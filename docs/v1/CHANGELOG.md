# v1.0.0 修订说明

日期：2026-11-22。本版将多份递增草案和增量台账整合成单一设计基线。

## 已完成

- 整理为17章、245条规范；字段、状态、权限、引用、恢复和失败语义交叉对齐。
- 登记89项独立错误/歧义/缺口，含原文依据、修正位置和验证方法。
- 补33份Schema、70个正反样例及5组摘要向量；明确文档校验不是产品测试。
- 为25个ADR补候选、验证、否决、降级和复审；为26项工程任务确定依赖和验收输出。
- 提供6份恢复/运维手册和135个具体待运行验收计划。
- 保留245个旧要求和141个旧验收编号的去向，原源逐字节存档。

## 有意保留的工程不确定性

没有选择未经实验的数据库/文件系统/系统镜像技术；没有声称零丢失、任意软件包兼容、全平台支持、集群HA或绝对即时撤权。全部技术ADR仍Proposed，所有产品实现NotVerified，产品测试NotRun。软件源码及实际运行证据仍须按 WI-001 核验。

完整逐项变更见[migration/findings.md](migration/findings.md)，编号冲突与字段迁移见[migration/v0-to-v1.md](migration/v0-to-v1.md)。

## 同版本文档增补（2026-11-22）

在保持 `VERSION = 1.0.0` 的前提下，当前 GitHub 分章补充 Agent 自主编排：Router/Worker、主动事件触发、任务/线程接续、委托权限、非 LLM Watchdog、根预算、恢复和 Forgejo/CI/Review 门禁，关联第 08/09/10/11/14 章。

本次未增加新的正式 V1 规范 ID、Schema 或已批准 ADR，工程 `NotVerified`、增量测试 `NotRun`。原始分段 ZIP 仍是增补前不可变封存快照；此前的静态 validation-report.json 只对增补前文档有效，不能冒充此次修改后的重验证记录。

## Shell 浏览器桌面专项修订（2026-11-25）

- 将 Shell 定位为类似 macOS 的浏览器桌面工作环境，补齐菜单栏、Dock、启动器、多窗口、工作区、全局搜索和桌面应用组织；系统管理作为独立应用提供。
- 新增 V1-SHL-001～012，明确窗口/后台任务生命周期、布局与权限恢复、KDE/GUI 分工、跨应用引用、第三方隔离、Agent 上下文、无障碍和资源预算。
- 新增 WI-027 与 AT-SHL-001～015；同步产品架构、路线、ADR-16 体验约束、接口词典和实际实现差距。
- 重新生成当前需求索引、场景阅读版、完整 Markdown、离线 HTML、校验报告与 MANIFEST；原始分段 ZIP 不覆盖，依然是 2026-11-22 封存交付。
- 文档版本保持 1.0.0，当前 GitHub 修订以提交 SHA 标识；新增桌面实现为 NotVerified、产品验收为 NotRun，静态检查不代表软件能力完成。

## Agent 通用接口与 Artifacts 应用化（2026-11-25）

- 新增 V1-APP-012～016、V1-AGT-013～015：统一产物交付、清单适配、受控安装、隔离预览、版本管理及独立制品保留。
- 说明能力发现、拟定逻辑操作、来源关联、幂等回执、预授权与断线恢复；复用 Application/Release/Deployment、Task/Operation 和现有权限模型。
- 新增 WI-028 与 AT-AIF-001～010，优先静态 Web/OCI；接入消息 Schema、运行实现和验收仍待完成。
- 同步架构、接口目录、任务结果边界、实现差距及派生文档；明确 GitHub 当前文档为唯一权威，历史 ZIP 保持不变。文档版本为 1.0.0，新增功能为 NotVerified/NotRun。

## OCI 私有运行目录（2026-11-28）

Release 资源规格新增可选 `run_max_bytes`，用于声明独立的 `/run` 临时空间。旧规格可继续验证。该字段按字节编码，具体页对齐、临时目录上限和运行身份由适用的 Runtime Profile 校验。此修订对应 AT-STA-013 中的临时挂载要求。[Release 资源规格](schemas/application-release-spec.schema.json)
