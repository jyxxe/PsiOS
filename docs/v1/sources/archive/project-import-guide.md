# PsiOS 项目说明与导入指南

目标位置：ChatGPT 原生 Projects（https://chatgpt.com/projects）中的 `PsiOS` 项目，而不是 Space。

## 规范优先级

1. 本项目的 v0.6 风险修订与统一 API/ADR 更正。
2. 已批准、附审查记录的 ADR 和 Schema。
3. v0.5 全量详细规范中的未修正条款。
4. v0.1～v0.4 历史草案，仅供历史溯源。

设计文档不能证明已实现；真实实现状态只根据最新 Forgejo HEAD、源码 SHA、制品摘要、CI/故障注入与恢复记录确定。

## 推荐上传顺序

优先上传 `core/01_PsiOS_统一规范_v0.6_项目导入版.md`、`core/02_PsiOS_v0.6_ADR与风险闭合.md`、`core/03_PsiOS_实施路线与验收清单.md`，并可将本文件作为项目说明或在项目设置中粘贴。`historical/` 五个原文件按需要上传，避免历史草案与最新规范争权。
